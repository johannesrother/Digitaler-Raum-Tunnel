# Asset Credits

All third-party visual assets in this project are stored locally and are loaded
from the repository at runtime. No visual asset is hotlinked.

Poly Haven publishes its models, texture maps and HDRIs as [CC0](https://polyhaven.com/license).
Attribution is not legally required, but is retained here for transparent course documentation.
